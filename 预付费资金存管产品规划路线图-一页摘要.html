模式 A · 预付费托管

自建
  • 资金已划转、托管冻结；形成应收、可周转
  • 银行托管、监管认可；C 端需预付全款
  • 适配：教培 / 健身等大额长期
⇄

模式 B · 先享后付

借力支付宝安心付（服务商模式）
  • 资金未划转、授信 / 代扣；未形成应收
  • 依赖支付宝信用；C 端无预付压力
  • 适配：小额高频、锁客 / 提转化
架构共用内核（规则引擎 / 定时任务 / 核销 / 记账映射 / 清分指令 / 退款联动），仅在能力接入层分轨：自建底座 ⇄ 安心付通道。
关键决策（8 项已确认） DECISIONS
1定位：自己推 + 挂银行（银行账户托管），不做商委平台配角
2争议边界：不做仲裁；N 天自动确认 + 规则偏商家 + 复用投诉流程
3账户底座：V1 支付账户 → V2 银行内部户 → V3 数币（远期）
4外部借力：成为安心付服务商，并行探索
5首发场景：教培（重庆）+ 本地生活（美容/健身/按摩）
6交付载体：V1 复用小冲/店务通后台；同步规划独立 C 端
7商业口径：监管费 ~1% + 收单 0.3% + 沉淀分润
8项目立项：以资金存管产品为主体发起立项
